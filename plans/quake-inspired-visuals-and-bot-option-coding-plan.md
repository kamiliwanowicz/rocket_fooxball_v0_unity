## Decisions

- assumption: Quake 2 reference defines visual hierarchy and material mood, not copied textures, geometry, exact colors, or copyrighted asset reuse.
- decision: keep `RetroGrass*` filenames/GUIDs but author warm brown industrial floor plates; keep `RetroWall*` filenames/GUIDs but author warm ochre wall slabs/ribs. Use `FloorTextureScale = (13,9)` and `WallTextureScale = (4,1)`; keep trim and imported-arena scales unchanged.
- decision: restore ten existing renderer-only `ArenaWallPylon` instances at `x = -48,-24,0,24,48`, north `z=-44`, south `z=44`; keep every gameplay collider unchanged and keep `ArenaRampRails` prohibited.
- decision: center directional illumination with `ProductionSunEuler = (90,0,0)` and reduce `ProductionSunShadowStrength` from `0.90` to `0.65`; keep sun intensity/color, soft-shadow mode, biases, ambient/fill lights, sky, fog, probes, and post-processing unchanged. Directional-light position has no illumination effect.
- decision: every launcher and shotgun exports four exact renderer groups: `WeaponMetal`, `WeaponDark`, `WeaponAccent`, `WeaponAccentCore`. Outer red accent uses transparent URP Lit; nested opaque emissive core supplies visible illuminated interior without custom refraction.
- decision: weapon glass values are fixed: shell base `(0.68,0.03,0.015,0.42)`, metallic `0`, smoothness `0.96`, occlusion `0.85`, bump `0.35`, emission off, transparent alpha blend, alpha clip off, `ZWrite=0`; core base `(0.25,0.005,0.002,1)`, metallic `0.15`, smoothness `0.80`, occlusion `0.90`, bump `0.50`, emission `(1,0.08,0.015)` strength `2.0`.
- decision: world-shotgun glass stays authored red and is removed from `teamTintRenderers`; existing character/cue colors remain team-readability owner.
- decision: `MatchController` owns bot configuration. Bots default on. Setup-only `BOTS ON/OFF` deactivates `BotSystems` and slots `1..5` while retaining fixed six-slot serialized roster and statistics. No live toggle or persistence.
- decision: disabling order is `BotSystems` off -> bot participant roots off. Enabling order is participant roots on -> reapply current gameplay gate -> `BotSystems` on. Rematch resets selection to authored default on; START locks selection for match.
- decision: preserve legacy `MatchRules` overloads and `DifficultyLocked` public surface by delegating to new configuration-aware APIs with bots enabled.
- decision: update repository Blender skill, not global/system skill. Skill applies only to Blender-authored 3D geometry, rigs, animation, `.blend`, and FBX work; it explicitly excludes procedural PNG/PBR texture generation even when scripts live under `Tools/Blender/` or run in Blender Python. Texture tasks follow `AGENTS.md` plus generator-owned CLI, output, determinism, and semantic-audit contracts. Triangle/vertex counts and review ranges become report-only; topology, transform, connectivity, bounds, slot, UV, axis, and export contracts remain hard failures.
- decision: split texture work sequentially because both tasks own `generate_retro_textures.py`: T1A owns floor/wall generator infrastructure and eight surface PNGs; T1B builds on accepted T1A state and owns thirteen weapon PNGs. Both texture workers use `sol_high`; reviews remain `sol_medium` per repository review policy.
- decision: source generators own raw PNG/FBX files; builder generation task alone owns importer metadata, materials, prefabs, scene, project settings, lighting/bake files, and manifests. No source worker edits generated YAML or `.meta` files.
